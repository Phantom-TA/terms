### Known limits

- **Not run against the real API.** The first integration run is Phase 6, once A's routes exist.
- **Bundle size.** The grid chunk is about 2.7 MB (770 KB gzip) and the chart chunk about 1.4 MB (420 KB gzip), because both register the all-in-one AG modules. Both are lazy-loaded. Switching to individual modules is planned for Phase 6.
- **Mock data.** `src/mocks/world.ts` reproduces the CONTEXT.md scenario with the shared money helpers. It never changes payment state.
