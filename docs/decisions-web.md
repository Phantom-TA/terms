# Web decisions

Decisions made where `CONTEXT.md` is silent or ambiguous, chosen to fit its principles and guardrails.

| ID    | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Why                                                                                                                                                                                                                                           |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| W-001 | The accent colour (pine green, `committed`) is used only for cash committed: committed figures, committed chart series, and deal states from AGREED on. Primary buttons are ink.                                                                                                                                                                                                                                                                                                                                                                         | CONTEXT.md asks for "one accent colour for cash committed". If buttons and links used it too, it would stop meaning anything.                                                                                                                 |
| W-002 | Light theme only. Colours are CSS variables, so a dark theme can be added later.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | The direction is a document-like desk, and a second theme doubles the contrast surface to verify.                                                                                                                                             |
| W-003 | `/style-guide` exists only in the dev server.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | It is internal and shows sample figures. Shipping sample money in a production build would break "never show fake success".                                                                                                                   |
| W-004 | The navigation comes from a screen registry, and a screen is listed only once it is built.                                                                                                                                                                                                                                                                                                                                                                                                                                                               | "No dead buttons: if an action isn't built, it isn't shown."                                                                                                                                                                                  |
| W-005 | Vite reads `@terms/shared` through the `@terms/source` condition in both dev and production builds.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | The output is bundled either way, and `vite build` then does not depend on a prior package build.                                                                                                                                             |
| W-006 | MSW's service worker is served from `node_modules` by a dev-only Vite middleware, never placed in `public/`. `scripts/check-prod-bundle.mjs` fails the build if mock code or server-only variable names reach `dist`.                                                                                                                                                                                                                                                                                                                                    | Everything in `public/` is copied into production builds. The contract is that mocks never ship, so the build enforces it.                                                                                                                    |
| W-007 | `pnpm-lock.yaml` is committed with the `apps/web` importer, as generated by `pnpm install`, in its own commit. It is never hand-edited.                                                                                                                                                                                                                                                                                                                                                                                                                  | The repo has one workspace lockfile and CI installs with `--frozen-lockfile`, so adding `apps/web` cannot pass CI without it. Treated as a generated file, not root config. If it conflicts with `a/core`, regenerate it with `pnpm install`. |
| W-008 | `apps/web` has its own ESLint and Vitest config. Root `lint` and `test` skip it by A's design, so the web gate runs through `pnpm --filter @terms/web gate`.                                                                                                                                                                                                                                                                                                                                                                                             | A's root configs exclude `apps/web` and say B owns its setup. A CI job for the web gate is requested in `docs/contract-requests.md`.                                                                                                          |
| W-009 | Every API response is validated with its shared schema, and a mismatch shows an error instead of partial data.                                                                                                                                                                                                                                                                                                                                                                                                                                           | "Never show fake success" extends to data the client cannot verify.                                                                                                                                                                           |
| W-010 | After the SSE connection comes back from a drop, all queries are refetched. Frames are also de-duplicated by event ID.                                                                                                                                                                                                                                                                                                                                                                                                                                   | A manual reconnect cannot send `Last-Event-ID`, so events may have been missed. Money on screen must not stay stale.                                                                                                                          |
| W-011 | The AG Grid licence key is passed with the `licenseKey` prop on `AgGridProvider`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | That is the v35.1+ API; `LicenseManager` is the older path.                                                                                                                                                                                   |
| W-012 | AG Grid Enterprise is lazy-loaded behind a skeleton, and every screen with a grid follows this pattern.                                                                                                                                                                                                                                                                                                                                                                                                                                                  | It is the largest dependency. A static import held back the whole page until it loaded.                                                                                                                                                       |
| W-013 | A page whose only content is an error or empty state uses an `h1`, through the `headingLevel` prop.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Every page needs a top-level heading for screen-reader navigation. axe caught this in the browser.                                                                                                                                            |
| W-014 | The Workbench puts the decision columns (action, amount asked, discount, cost) right after the client. Deal state, committed cash and approval are pinned to the right on wide screens and scroll with the rest on tablets. A column picker lets the owner hide any column.                                                                                                                                                                                                                                                                              | All 16 columns from CONTEXT.md cannot fit at 1366px. The columns an owner edits and the outcomes they watch must always be in view; the invoice context can scroll.                                                                           |
| W-015 | The grid never changes its own data. A cell edit is pre-checked with the shared policy functions, sent to the server, and the grid shows whatever the server returns. The row is dimmed while a change is in flight.                                                                                                                                                                                                                                                                                                                                     | "The UI never shows a success that the server didn't confirm." A local optimistic edit would show a plan the server may have refused.                                                                                                         |
| W-018 | Approving does not block a ceiling below the plan's cost. The dialog warns, and the server decides.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | CONTEXT.md says anything over the ceiling comes back to the owner. The server is authoritative about what it accepts.                                                                                                                         |
| W-019 | Groups are ordered offers, reminders, nothing to do, then "Do not contact". Protected clients are always their own group, whatever their action.                                                                                                                                                                                                                                                                                                                                                                                                         | Protected clients should be visibly protected, and last, so they never look like part of the plan.                                                                                                                                            |
| W-020 | AG Grid column virtualisation is off in the Workbench.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | There are at most 16 columns and tens of rows, so it costs little. Every cell is then in the page for screen readers and in-page search, and for tests.                                                                                       |
| W-021 | On wide screens the plan rail and the runway chart sit side by side; on tablets they stack. The chart can be collapsed.                                                                                                                                                                                                                                                                                                                                                                                                                                  | At 1366×768 a stacked chart pushed the grid, the main working surface, below the first screen.                                                                                                                                                |
| W-022 | The edit handler is passed to AG Grid through a stable function (`useStableCallback`), not a fresh closure per render.                                                                                                                                                                                                                                                                                                                                                                                                                                   | New column definitions on every render reset the grid's column state.                                                                                                                                                                         |
| W-023 | Chart colours are constants mirrored from the design tokens, with a test that fails if they drift.                                                                                                                                                                                                                                                                                                                                                                                                                                                       | AG Charts takes colour strings, not CSS variables.                                                                                                                                                                                            |
| W-024 | Mock mode exposes `window.__termsMockEmit` to push server events into the mock stream. It lives in `src/mocks` and the production bundle check fails if it ships.                                                                                                                                                                                                                                                                                                                                                                                        | Browser tests need to show live updates without a real server.                                                                                                                                                                                |
| W-016 | The payroll threshold is a horizontal line at its amount, in red, with a quiet vertical marker on the day it lands. The zero line is neutral.                                                                                                                                                                                                                                                                                                                                                                                                            | `RunwayThreshold` is defined as a labelled horizontal reference line, and it tells the demo's story: the balance sits below the line, and the plan lifts it above.                                                                            |
| W-025 | The Workbench asks for closed invoices too and keeps those that are part of the plan. Closed invoices outside the plan are left out.                                                                                                                                                                                                                                                                                                                                                                                                                     | A deal must stay on screen as PAID, not vanish at the moment it succeeds.                                                                                                                                                                     |
| W-026 | Plan edits are sent one at a time, in the order they were made.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `plan` comes back whole from each edit, so an out-of-order response would overwrite a newer plan.                                                                                                                                             |
| W-027 | Function options passed to AG Grid are module-level constants, and an unchanged invoice keeps the same row object.                                                                                                                                                                                                                                                                                                                                                                                                                                       | AG Grid treats a new function as a changed setting and closes any open editor, which could commit a half-typed value. With stable options, rows can keep updating while the owner edits.                                                      |
| W-028 | A draft row with an action shows as Suggested, though the API creates deals only on approval.                                                                                                                                                                                                                                                                                                                                                                                                                                                            | CONTEXT.md defines SUGGESTED as in the plan and not yet approved. The plan's DRAFT status is the server's word for that.                                                                                                                      |
| W-029 | Switching a row to an early-payment discount asks for the whole invoice. Switching a whole-invoice row to a partial payment asks for half, in $250 steps, which the owner can change.                                                                                                                                                                                                                                                                                                                                                                    | The API rejects an action that doesn't fit the amount, so one edit has to send both.                                                                                                                                                          |
| W-030 | A name the goal parser could not match keeps its warning for as long as that goal is shown.                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Saving the list by client ID drops the name, and an unmatched name protects nobody.                                                                                                                                                           |
| W-017 | The Policy column shows only the checks that need attention and counts the rest. The row's detail lists them all. It reads the server's `policyChecks` (contracts-v2).                                                                                                                                                                                                                                                                                                                                                                                   | A row can carry seven checks, nearly always passing. Seven badges per row would hide the one that matters.                                                                                                                                    |
| W-031 | The Negotiation Room opens on the most pressing conversation, then stays on it. It moves on its own only to a deal that starts needing the owner. Choosing a deal or deciding an approval pins it in the address.                                                                                                                                                                                                                                                                                                                                        | Live updates reorder the list. Reading a conversation must not be interrupted, but a NEEDS_OWNER card is the one thing the owner has to see.                                                                                                  |
| W-032 | A `deal.updated` event older than the deal on screen is ignored, by `updatedAt`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | An event can arrive after a newer fetch, and a deal must never appear to move backwards.                                                                                                                                                      |
| W-033 | The approval card comes before the conversation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | At 1366×768 it fell below the fold, and it is the only thing in the room the owner acts on.                                                                                                                                                   |
| W-034 | PayPal call chips list audit entries with a `paypalCall` or a webhook verification result, oldest first.                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Those are the steps that touched PayPal. The rest of the audit trail has its own screen.                                                                                                                                                      |
| W-035 | Reminder deals are not shown in the Negotiation Room.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | A reminder has no counterparty agent and nothing to negotiate. Its state is on the Workbench.                                                                                                                                                 |
| W-036 | The client's Payables Desk is the client's home and lists offers in the order the server sends them. The browser never re-ranks them or works out a return.                                                                                                                                                                                                                                                                                                                                                                                              | CONTEXT.md ranks offers by annualised return, and the server already computes it. Sorting in the browser could disagree with the agent's recommendation beside it.                                                                            |
| W-037 | Approving a client payment opens PayPal's invoice page in a new tab when the client has no saved method; with one, the agent pays. Either way the Payables Desk shows the payment as waiting for PayPal confirmation, with a link to the invoice, until `deal.updated` says PayPal confirmed it. The tab is opened at the click and given the address when the server answers, so browsers don't block it.                                                                                                                                               | A confirmed in CR-4 that `paypalApprovalUrl` is the PayPal invoice page, that PayPal doesn't redirect back, and that Terms learns of the payment from the verified webhook. Nothing counts as paid before that.                               |
| W-038 | Saving a PayPal method sends the person to PayPal and back to `webPaths.vaultReturn()` (`/client/vault/return`), which confirms once and then returns to the desk. `webPaths.vaultCancel()` says nothing was saved. Neither page appears in the navigation.                                                                                                                                                                                                                                                                                              | These are the return and cancel URLs A's vault service gives PayPal. They are pages a person lands on, not places to go.                                                                                                                      |
| W-039 | In development only, `/mock-paypal` stands in for PayPal's approval page so the redirect can be tried in mock mode. It follows only in-app paths, Vite drops it from builds, and the bundle check fails if its text is present.                                                                                                                                                                                                                                                                                                                          | Mock mode has no PayPal. Without a stand-in, the redirect would be the one step of the client's journey that could not be exercised.                                                                                                          |
| W-040 | In mock mode the stand-in PayPal invoice page runs in its own tab and tells the app's tab over a `BroadcastChannel` that it was paid; that tab then plays PayPal's verified webhook. Coming back from the stand-in saved-method page is still a full page load, which restarts the demo world, so the mock accepts that client's fixed setup token.                                                                                                                                                                                                      | Each tab has its own copy of the mock. The channel lets the payment flow be tried end to end the way the real one works: paid elsewhere, confirmed by webhook.                                                                                |
| W-041 | The public offer page sits outside the app shell and needs no session. A used or invalid link gets a page of its own with no retry; an ended offer shows what happened and no buttons.                                                                                                                                                                                                                                                                                                                                                                   | CONTEXT.md requires valid, expired and used states. A retry on a used link cannot succeed, so offering one would be a dead button.                                                                                                            |
| W-042 | On the offer page, the server's reply message stays on screen even when the reply closes the offer, and focus moves to it. A written reply shows how the server read it, called a best guess.                                                                                                                                                                                                                                                                                                                                                            | The person needs to see what happened to their answer. CONTEXT.md treats free-text promises as best effort, so the page does not present them as agreed.                                                                                      |
| W-043 | Pay part now does not show a price for the part before it is sent. The page states the discount rate and minimum, and the server's reply gives the amount.                                                                                                                                                                                                                                                                                                                                                                                               | The browser never computes payment outcomes.                                                                                                                                                                                                  |
| W-044 | Audit filters for who and what go to the server. The search box filters only the entries already loaded, and says so by its label.                                                                                                                                                                                                                                                                                                                                                                                                                       | Filtering by actor and action is in the API. Free-text search is not, and a search that looked server-wide would mislead.                                                                                                                     |
| W-045 | The owner's never-contact list offers every client business, plus anyone already blocked.                                                                                                                                                                                                                                                                                                                                                                                                                                                                | A block on a client with no open invoice must still be removable.                                                                                                                                                                             |
| W-046 | Each side sees only its own records, as A confirmed in CR-4. Both see the negotiation messages, PayPal's steps and every state change of a shared deal; each sees only its own approvals, reasons and policy checks. A message's checks go only to the side that sent it, and the other side's moves read a neutral reason ("Countered"), as the server does. The owner's Negotiation Room says only that the client pays through PayPal, and a client's notes no longer state its limits. The mock applies the same rules to deals and the audit trail. | No owner ceiling or max-discount reasons for the client, and no client limits for the owner.                                                                                                                                                  |
| W-047 | A closed deal shows the viewer's own reason for closing, taken from its history, and nothing when all it has is the public word for the state.                                                                                                                                                                                                                                                                                                                                                                                                           | Since contracts-v3, `closedReason` is the public text ("Declined"), which only repeats the state. The side that closed the deal still needs to read why.                                                                                      |
| W-048 | The cash strategist is the only agent in Cash Studio. Its tools are view schema, page and widget, run a query, add and place a widget, and configure a line, column or value widget. It has no tool to change the data model, filter, delete or reach outside Studio.                                                                                                                                                                                                                                                                                    | CONTEXT.md calls for read-only tools. In Studio the tools array is the boundary: whatever the model answers, the browser runs only what is listed.                                                                                            |
| W-049 | Each `configureWidget` listing is renamed (`configure_line_chart`, `configure_column_chart`, `configure_value`).                                                                                                                                                                                                                                                                                                                                                                                                                                         | Otherwise all three reach the model as `configure_widget`, and it can't tell them apart.                                                                                                                                                      |
| W-050 | Studio's system prompt and developer messages are not sent to `/api/studio/turn`. The newest messages are kept, starting at a user message.                                                                                                                                                                                                                                                                                                                                                                                                              | The prompt is the server's (the contract has no field for it). Starting at a user message means a tool result is never sent without the call it answers.                                                                                      |
| W-051 | Cash Studio shows the chat beside the widgets, with no data or compose panel, on a 12-column page with a 360px minimum width. Studio is themed from the design tokens: the focus blue as accent, ink-3 for quiet text.                                                                                                                                                                                                                                                                                                                                   | The strategist does the composing. The data panel covered the widgets on a tablet and nests a button inside a button. Studio's default accent and step text fail WCAG AA on the paper surface.                                                |
| W-052 | In mock mode the strategist follows a script per kind of question, calls only tools the browser offered, and invents no figures. For a what-if it names the server tool that would answer and charts the current runway.                                                                                                                                                                                                                                                                                                                                 | The browser never computes payment outcomes. A made-up what-if in the mock would look like a result.                                                                                                                                          |
| W-053 | The AG Studio licence key comes from `VITE_AG_STUDIO_LICENSE_KEY` through `AgStudioProvider`.                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Like the AG Grid key, it is designed to ship in the bundle; the server is not involved.                                                                                                                                                       |
